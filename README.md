# 말랑 크레인 (29)

실제 기계처럼 조작하는 3D 인형뽑기. 갤럭시·아이폰 브라우저 기준 세로 화면으로 만들었습니다.

## 조작

- 레버: 집게 전후좌우 이동 (PC는 방향키)
- 회전 버튼: 내려가기 전에 집게 방향 조절 (PC는 `Q`, `E`)
- `내리기`: 집게 하강 (PC는 `Space`). 내려가는 동안 집게가 매번 다른 패턴으로 돌아 방향을 고를 수 없음
- `집기`: 내려가는 중 다시 누르면 그 자리에서 집음. 안 누르면 바닥 근처에서 자동으로 집음

## 실행

```
npm install
npm run dev     # 개발 서버
npm run build   # 타입 검사와 빌드
npm run sim     # 화면 없이 뽑기를 반복해 성공률 측정
```

주소 뒤에 `?auto`를 붙이면 자동으로 플레이합니다.

## 구조

- `src/sim.ts`: 규칙과 물리(Rapier). 성공 여부를 미리 정하지 않고 물리 결과로 판정
- `src/machine.ts`: 기계·집게 그래픽
- `src/plush.ts`: 인형 모델과 털. `SPECIES` 항목을 바꾸면 인형 종류를 교체할 수 있음
- `src/main.ts`: 화면과 입력 연결

## 개인정보

입력값은 서버로 보내지 않습니다. 로그인과 서버가 없습니다.
